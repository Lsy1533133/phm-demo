02 / 08 PROBLEM DEFINITION
AI 药物研发的幻觉危机
LLM 看起来很对，但实际在编造——在药物研发中这意味着致命
1
编造药物靶点数据
LLM 生成看起来合理的 d_eff、η、IC50 数值，实际与物理引擎计算结果完全不符。无校验层时，幻觉率高达 52%。
实测：421/815 场景出现幻觉（无 PHM）
2
虚假文献引用
AI 生成不存在的论文 DOI、编造临床试验 NCT 编号。在 fake_citation 攻击测试中，无校验时 59% 幻觉率。
实测：20/34 场景被虚假引用欺骗（无 PHM）
3
概念混淆与相态误判
将 η（耦合强度）误述为错误率，将 d_eff（有效维度）误述为码距，或将 UNCORRECTABLE 判定为安全。概念混淆攻击 39% 幻觉率。
实测：16/41 相态判断错误（无 PHM）

定位
PHM 是 Agent 基础设施——不与任何 AI Agent 竞争，而是让所有 Agent 更可信。可接入任何 LLM（DeepSeek / GPT / Claude / Gemini），任何 Agent 框架（LangChain / AutoGPT / CrewAI）。在生物医药领域，HESC 定位为「AI 药靶物理验证引擎」，与 Insilico/NVIDIA Bio 等生成式平台互补——它们生成靶点，PHM 验证靶点。
